# AJAX Student CRUD (PHP + MySQL)

This example is a server-side PHP project. It will not execute on GitHub Pages.

## Local setup

1. Install and open XAMPP (or another PHP + MySQL environment).
2. Copy the repository into your local web server's document root.
3. Start Apache and MySQL.
4. Create a MySQL database named `college`.
5. Import `college.sql` into that database using phpMyAdmin.
6. Check `conf.php` and update the database host, username, password, and database name for your local environment.
7. Open the project through your local server, for example:

   `http://localhost/website-templates-main/applications/backend/ajax-php-crud/`

Use only local/test data. Do not commit production database credentials or private records.
